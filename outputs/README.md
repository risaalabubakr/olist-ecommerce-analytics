# Selected analysis outputs

This folder is reserved for carefully selected, sanitized and aggregated outputs that add value beyond the notebooks, SQL script and Power BI dashboard.

Suitable examples include a state-level delivery summary, seller-segment summary or product-category summary exported from the analytical views.

Do not upload raw Olist CSVs, customer-level records, credentials, connection strings or temporary files. Prefer documenting a result in the README or KPI Dictionary rather than committing multiple versions of the same export.
