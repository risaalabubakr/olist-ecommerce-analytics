# Data

The project uses the public Olist Brazilian e-commerce dataset (2016–2018).

Place the source CSV files in this folder locally. The raw dataset is not committed here; obtain it from its original public source and keep large raw files out of Git unless there is a clear reason to version them.

Expected source tables: orders, customers, order_items, order_payments, order_reviews, products, sellers, geolocation and product_category_name_translation.
